# Tiga Bab, Satu Takdir — Edisi Audio (untuk Ki)

This project adds original, locally hosted music and sound effects to the v3 cinematic game.

**What's new**
- Four original instrumental tracks: Langkah, Melodi, Damai and birthday finale.
- Three looping environment ambiences: garden/birds, rain and quiet library.
- Thirteen short effects for puzzles, notes, correct answers, hints and gifts.
- Audio settings: independent music, ambience and effects volumes, plus ambience toggle.
- Audio starts only after the player taps the ♪ button or **Hidupkan Audio** in ⚙ settings, which is needed for iPhone Chrome and Safari.
- Sound puzzles remain playable with sound muted, because visual information is preserved.
- Volume preferences are saved locally. Existing puzzle progress remains compatible.

**Important**: This is an interactive, stylized browser adventure, not a studio-quality animated film.

## Publish on GitHub Pages (free)
1. Extract this ZIP.
2. Upload **all files and folders** including `audio/` into the root of your GitHub repository.
3. In Settings → Pages, publish from `main` / `(root)`.
4. Open `https://USERNAME.github.io/REPOSITORY/`.
5. Tap ♪ to begin the soundtrack.

If you are uploading from an iPhone, a standalone `index.html` is also provided separately.

All audio included in this package was programmatically synthesized specifically for this project and does not use commercial recordings.


## Illustrated visual edition
This edition uses actual generated PNG backgrounds and gift art in `art/` (home, three chapter environments, three gift reveals, and finale), plus chapter-zone illustrated crops. Puzzles use visual, tappable boards with original correctness rules and all 3 hints. Audio remains locally bundled. Static files may be uploaded directly to GitHub Pages. Recommended: use desktop GitHub web interface or git to preserve folders; do not upload the ZIP itself.
